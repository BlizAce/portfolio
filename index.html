Giving an LLM shell access is easy. Keeping it safe across hour-long autonomous runs is the engineering:

  • Hard-deny layer — rm -rf /, raw device writes, fork bombs and fetch-piped-to-shell are never executed, even with approval or YOLO mode.
  • Persistent permission rules — Allow once / Always / Never dialogs that survive restarts and can't resurrect a hard-deny.
  • Prompt-injection quarantine — web pages are digested by a reader agent holding entirely inert tools; any tool call flags the URL and its content never reaches the main agent.

All of this ships in Penguin Command.
