🐧 Penguin Command

A terminal that runs inside any terminal — with an AI system assistant one keystroke away. Real PTY, real shell, custom VT emulator, and a safety engine built for autonomous runs.

RustCustom VTEOpenAI-compatible + AnthropicLinux · macOS · WindowsMIT

Drop-in, not a replacement. Your shell keeps running underneath. Ctrl+Space slides into agent mode; toggle off and your terminal is exactly where you left it — scrollback, running programs and all.

Goals, not prompts

/goal <thing> hands the agent autonomy: it plans minor goals, executes with real tools, and must prove success with a check before the ★ VERIFIED banner lands.

  • Auto-continuation — if the model stops before verifying, penguin picks it back up, plan intact.
  • Mid-run steering — anything you type is injected at the agent's next step; no abort needed.
  • The agent asks you back — ask_user() pops selectable options when it needs a decision.
  • Sessions checkpoint every step — a crash loses at most one move; /resume restores the sidebar exactly.

Safety is the product

Autonomy without blast-radius control is a liability. Three layers stand between the model and your machine:

  • Hard deny — rm -rf /, raw disk writes, fork bombs, curl | sh. Never executed. Not even in YOLO mode.
  • Permission gates — anything outside the workspace pops Allow once / Always / Never; rules persist.
  • Injection quarantine — web pages are digested by a reader agent holding entirely inert tools. Any tool call flips the URL dirty and its content never reaches the main agent.

Built for slow thinking

Tuned for local reasoning models that spend minutes thinking before they speak:

  • Chain-of-thought streams in its own live panel — the screen never looks frozen.
  • Elapsed timers, tok/s readouts and per-tool run timers on everything.
  • Thinking depth is a live dial: /effort low·med·high·xhigh.
  • Context meter with auto-compaction at 85% — and hard-compact recovery when a provider rejects the prompt.

…and yes, leave it idle and ASCII penguins take over. Waddling through a blizzard under an aurora. Any key wakes them.
