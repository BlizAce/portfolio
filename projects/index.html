🧰 The unglamorous 90%

DevExOps

A full experimental harness for architecture claims at ≤10M parameters: training pipelines, benchmark scripts, an ablation framework and provenance audits.

  • Dense dominates the fractal frontier at every matched cost point — 5 of 5 configurations.
  • Weight tying cuts parameters 87% while leaving MACs/item exactly unchanged: parameter sharing is not compute sharing.
  • An oracle bound showed adaptive depth had +0.00 points of headroom — the direction was provably dead before more GPUs were spent on it.

The funnel-routing report: a mixture-of-experts architecture evaluated with the controls that later became the eight-gate protocol.

  • Plateau-matched generalisation flipped one comparison's sign — the "loser" was merely slower to converge.
  • Routed-fraction thresholds exposed improvements riding on too few items to matter at scale.
  • Routing load distributions measured, not assumed — hot slots, cold retirement and cohesion tracked per run.

The eight controls → ⬇ Report PDF

The layer nobody screenshots and everyone depends on:

  • Installers — install.sh / install.ps1 bootstrap Rust if needed, honour PC_INSTALL_DIR, wire shell integration for bash/zsh/fish/PowerShell; uninstall with --purge.
  • Watchdogs — user-level systemd services with 30s health loops keep Spider Net alive across boots and crashes.
  • Docker pipelines — one command builds, starts, health-checks, logs and shells in.
  • Checkpointed state — sessions save after every step; atomic guarantees keep crawler state and index from diverging under failure.

Penguin Command and Spider Net both install on a fresh machine in under two minutes.
